# Security Policy

The plugin runs a shell script on Claude Code hook events and writes terminal escape sequences. Message text is sanitized (control characters and `;` stripped) before it reaches your terminal.

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/SiriWastaken/claude-needs-input/security/advisories/new) rather than a public issue. Expect a reply within a week.

## Supported versions

Only the latest release receives fixes.
